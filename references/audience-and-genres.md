# 受众与文种

## 受众决定信息如何展开

先判断读者已知什么、需要理解什么、看完需要采取什么行动。同一事实面向不同读者时可以改变解释深度和顺序，不能改变适用条件、责任、工作状态或结论强度。

| 主要读者 | 优先写清 | 表达处理 |
|---|---|---|
| 决策者、机关负责人 | 当前判断、依据、影响、选项和待决定事项 | 结论适当前置，保留必要论证；不因“给领导看”就自动压成一页 |
| 执行岗位、内部人员 | 适用事项、动作、分工、节点、例外和反馈路径 | 术语可保留，但首次出现的内部缩写需明确；不要只有动员口号 |
| 其他部门、协作单位 | 共同事项、职责边界、需配合内容、条件和期限 | 解释本部门专用术语；请求、协商与已确定职责分别表达 |
| 企业、社会组织等办事主体 | 是否适用、需要做什么、材料、时限、渠道和可能影响 | 按读者办事顺序组织，关键术语首次简释，不省略条件 |
| 社会公众 | 与其相关的变化、何时何地、如何办理或求助 | 采用熟悉词语和短段落，地址、时间、渠道等关键事实便于查找 |

不把组织内部简称直接当作公众已知概念。解释术语时可以用“本通知所称……，是指……”或一句通俗说明；准确的正式名称仍予保留。面向公众的材料只放入与告知事项有关、适合公开的信息；不擅自把内部附件或个人信息转入公开稿。

## 按用途选文种和结构

以下是组织内容的起点，不要求逐项填满。用户已有标题、单位模板或明确文种时优先沿用，发现用途与文种明显不符时说明具体影响并提出调整。篇幅长短本身不能决定文种。

| 任务 | 核心问题 | 可采用的组织方式 |
|---|---|---|
| 情况报告、工作汇报 | 目前怎样，问题影响什么，已经和准备怎样处理 | 主要情况 → 关键进展或问题 → 原因和影响 → 后续安排 |
| 改革建议、专题签报 | 为什么需要改，方案怎样起作用，需要决定什么 | 核心建议 → 问题及依据 → 拟议机制与条件 → 待决定事项 |
| 请示 | 请求决定或批准的具体事项是什么 | 请求事项及必要背景 → 理由与条件 → 明确请求；多个独立事项应检查是否适合分开 |
| 批复、答复 | 对来文事项作出什么答复，适用哪些条件 | 对应来文及事项 → 明确意见 → 必要条件和后续安排；未获授权的决定不得代作 |
| 通知 | 哪些对象需要知道或执行什么 | 事项与目的 → 适用对象 → 具体安排 → 责任、期限和渠道 |
| 函、商洽材料 | 需对方协商、配合、说明或答复什么 | 共同事项和必要背景 → 具体请求或答复 → 时间及联系安排 |
| 公告、通告等公开告知 | 应向谁公开什么事项，有何影响 | 告知事项 → 范围、时间和条件 → 公众行动路径；文种名称按实际权限和用途确定 |
| 工作意见、实施方案 | 要达到什么目标，怎样推进和检查 | 目标与条件 → 任务措施 → 责任、节点和保障；义务强度须与依据和权限相符 |
| 工作总结 | 已做什么，结果如何，还有什么不足 | 按重点任务串起做法、进展、问题和后续措施，也可分节组织 |
| 调研、政策研究报告 | 材料支持什么发现，原因与建议依据何在 | 问题与材料范围 → 发现及证据 → 原因、约束和可选路径 → 建议 |
| 讲话、讲话提纲 | 希望听众理解什么，接下来做什么 | 场合和核心信息 → 关键认识 → 具体要求；层次和句长服从可听懂程度 |
| 会议纪要 | 会议实际研究、决定或保留了什么事项 | 会议事项 → 实际形成的意见 → 分工和后续安排；未决分歧不得写成一致决定 |
| 经验交流、党建材料 | 哪种做法怎样起作用，何处可借鉴 | 起点问题 → 组织和运行机制 → 已有变化 → 适用条件；总结、方案、调研仍按相应任务组织 |

报告以说明情况为主。需要明确审批、授权或资源决定时，应把待决定事项清楚列出，并按行文关系和单位要求核对采用请示、签报或其他适当形式，避免把实质请求埋在背景中。跨部门协作材料不得凭措辞替对方新增职责。

## 摘要和短材料

阅读摘要保留核心情况、关键事实、影响和下一步；没有待决定事项时不制造审批请求。决策摘要突出需要决定什么、依据和约束、方案差异及执行前提；资料不足时不虚构备选方案的成本收益。

口头提纲应便于说出和听懂。保留主题判断、必要事实和下一步，复杂数字可另附，但主体、分母及关键条件不能丢失。时长需要试读估计，不能仅凭字数保证。

短文同样核对事实、权限和状态。用户要求完整报告时，不以摘要替代正文；需要时可另附摘要。法定文种的版式和机关要素另按本包的 Word 与版式参考处理，仅写出程式用语不代表格式已符合要求。
